Инструкция: Публикация на GitHub Pages

Загрузив этот проект на GitHub, вы получите бесплатную постоянную веб-ссылку, которую можно разместить на сайте школы, в мессенджерах или на личной странице класса!

1

Создайте файл index.html

Сохраните код этой страницы под именем index.html на своем компьютере.

2

Зарегистрируйтесь и создайте репозиторий на GitHub

Зайдите на github.com, нажмите кнопку «New Repository» (Новый репозиторий). Назовите его, например: class-games. Сделайте его Public (Публичным).

3

Загрузите файл index.html

В созданном репозитории нажмите «uploading an existing file», перетащите ваш файл index.html и нажмите зеленую кнопку «Commit changes».

4

Включите GitHub Pages

В репозитории перейдите во вкладку Settings (Настройки) → слева выберите Pages. В разделе Branch выберите main (или master) / root и нажмите Save.

5

Готово! Получите ссылку

Через 1-2 минуты обновите страницу GitHub Pages. Появится ссылка вида:
https://ваш-логин.github.io/class-games/. Скопируйте её и разместите на странице вашего класса!
